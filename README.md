# HealthCure Diagnostic — UI Showcase

A visual portfolio showcase of **HealthCure Diagnostic**, a laboratory management platform designed to support day-to-day pathology lab workflows.

> **Showcase repository only:** this repository contains screenshots and a redacted sample PDF report. It intentionally does **not** contain the application source code, backend, database, credentials, patient records, or a runnable build.

## Live system and privacy

The platform is currently used in a working pathology-lab environment. This public repository is intentionally limited to presentation material. It does not provide access to the operational system.

For privacy and security, do not publish real patient information, login credentials, API keys, database exports, private configuration files, or internal source code in this repository.
